# Apis3 · Consumo de APIs REST

Tres aplicaciones web que consumen APIs públicas con **JavaScript** y la **Fetch API**, sin frameworks.

| Proyecto | API | Qué hace |
|---|---|---|
| `EjercicioClima/` | [OpenWeather](https://openweathermap.org/api) | Busca el clima actual por ciudad y país: temperatura, descripción y humedad. Valida el campo vacío y maneja ciudades no encontradas. |
| `EjercicioFotos/` | [The Cat API](https://thecatapi.com/) | Galería de imágenes cargadas desde la API. |
| `EjercicioPokemon/` | [PokéAPI](https://pokeapi.co/) | Pokédex con tarjetas por Pokémon (número, tipos, altura y peso) y filtro por tipo. |

## Qué practica

- Peticiones HTTP con `fetch` y manejo de promesas.
- Lectura de respuestas JSON y renderizado dinámico en el DOM.
- Manejo de errores (respuestas no exitosas y fallos de red).

## Cómo verlo

Abre el `index.html` de cada carpeta en el navegador. Para el clima necesitas tu propia clave gratuita de OpenWeather en `EjercicioClima/clima.js`.

---

**English:** Three small web apps that consume public REST APIs with plain JavaScript and the Fetch API: a weather lookup (OpenWeather), an image gallery (The Cat API) and a Pokédex with type filters (PokéAPI).
